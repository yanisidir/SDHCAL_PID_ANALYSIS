# License Selection Note

No final license has been selected for this repository yet. Until an explicit license is chosen and committed, the default legal position is that no broad reuse rights are granted beyond normal viewing of the public repository.

## Suggested Direction

For internship research software intended as a portfolio repository, a permissive code license is usually the easiest for reviewers and future collaborators to understand. Common options are:

- MIT License: short and permissive.
- BSD-3-Clause License: permissive, with an explicit non-endorsement clause.
- Apache-2.0 License: permissive, with more detailed patent language.

For documentation and author-owned figures, a Creative Commons license such as CC BY 4.0 can be considered separately. Before choosing a license, confirm whether any dataset terms, collaboration rules, upstream software licenses, or institution requirements affect code, figures, or derived outputs.

This file is a recommendation note, not a restrictive license choice.
